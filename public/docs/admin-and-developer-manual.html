Cancer Care Bangladesh (CCB)

অ্যাডমিনিস্ট্রেটর ও ডেভেলপারদের জন্য সম্পূর্ণ টেকনিক্যাল অপারেশনস, সার্ভার ডিপ্লয়মেন্ট, কোডবেস স্ট্রাকচার, ইউজার মডারেশন ও ট্রাবলশুটিং ম্যানুয়াল।

১. ডেভেলপার ও ডেভঅপ্স নির্দেশিকা (Developer & DevOps Guide)

১.১ সার্ভার ও এনভায়রনমেন্ট রিকোয়ারমেন্টস

  • PHP: ^8.2 (প্রয়োজনীয় এক্সটেনশন: pdo_mysql, mbstring, bcmath, intl, gd, redis, curl)।
  • Database: MySQL 8.0+ (Default Collation: utf8mb4_unicode_ci — বাংলায় ইউনিকোড সাপোর্টের জন্য আবশ্যক)।
  • Queue / Cache: Redis 6.0+ (অ্যাসিঙ্ক্রোনাস জব ও নোটিফিকেশনের জন্য)।
  • Package Managers: Composer 2.6+, Node.js 18.0+ এবং NPM।
  • Storage: AWS S3 অথবা যেকোনো S3-সামঞ্জস্যপূর্ণ স্টোরেজ (MinIO / Wasabi / DigitalOcean Spaces)।

১.২ লোকাল প্রজেক্ট সেটআপ স্টেপ-বাই-স্টেপ

# ১. রিপোজিটরি ক্লোন করুন git clone https://github.com/Rezaul44/cancercare.git cd cancercare # ২. প্যাকেজসমূহ ইনস্টল করুন composer install npm install # ৩. এনভায়রনমেন্ট তৈরি করুন cp .env.example .env php artisan key:generate # ৪. ডাটাবেজ মাইগ্রেশন ও সিডার চালান php artisan migrate --seed # ৫. স্টোরেজ লিংক তৈরি করুন php artisan storage:link # ৬. ফ্রন্টএন্ড বিল্ড করুন npm run build # ৭. সার্ভার চালু করুন php artisan serve

১.৩ প্রোডাকশন ক্রন শিডিউলিং (Crontab Setup)

সার্ভারে লারাভেল শিডিউলার সক্রিয় রাখতে সার্ভারের crontab-এ (crontab -e) নিচের লাইনটি কনফিগার করুন:

* * * * * cd /path-to-cancercare && php artisan schedule:run >> /dev/null 2>&1

যা যা স্বয়ংক্রিয়ভাবে চলবে:

  • রাত ০১:০০ টা: ExpirePatientCases — মেয়াদোত্তীর্ণ প্রকাশিত কেসের স্ট্যাটাস expired করে।
  • রাত ০২:০০ টা: sitemap:generate — গুগলে দ্রুত ইন্ডেক্সিংয়ের জন্য সাইটম্যাপ আপডেট করে।
  • সকাল ০৯:০০ টা: NotifyCaseExpiring — যেসকল কেসের মেয়াদ ৫ দিন বা কম বাকি তাদের জন্য স্টাফদের বেল নোটিফিকেশন পাঠায়।

২. অ্যাডমিনিস্ট্রেটরদের অপারেশনাল ওয়ার্কফ্লো (Administrator Manual)

১

ইউজার ও স্টাফদের রোল প্রদান

অ্যাডমিন প্যানেলে (/admin/users) গিয়ে নতুন স্টাফ নিয়োগ ও তাদের কাজের সুনির্দিষ্ট রোল সিলেক্ট করুন:

  • verification_officer: ডাক্তার ও রোগীর কাগজপত্র যাচাই ও ফিল্ড রিপোর্ট পর্যালোচনার জন্য।
  • support_agent: হেল্পলাইন অনুসন্ধান, প্রাথমিক কেস ড্রাফট ও বিকাশ অ্যাকাউন্ট ভেরিফিকেশনের জন্য।
  • field_agent: সরাসরি রোগীর বাড়ি বা হাসপাতালে গিয়ে পরিবার সাক্ষাৎকার ও সম্মতিপত্র গ্রহণের জন্য।
  • medical_reviewer: ডাক্তার প্রোফাইল ও ক্যান্সার গাইড পর্যালোচনার জন্য।
২

ডাক্তার আবেদন অনুমোদন ওয়ার্কফ্লো

  1. Doctor Applications মেনুতে যান।
  2. চিকিৎসকের নাম ও BMDC রেজিস্ট্রেশন নম্বর সরকারি BMDC ডাটাবেজে যাচাই করুন।
  3. চিকিৎসকের ডিগ্রি ও বর্তমান কর্মস্থলের সত্যতা নিশ্চিত হলে "Approve" বাটনে ক্লিক করুন। সাথে সাথে ডাক্তারের নতুন প্রোফাইল তৈরি হবে ও পাবলিক ডিরেক্টরিতে প্রকাশিত হবে।
৩

রোগীর সহায়তা ও ৪-ধাপের ভেরিফিকেশন পরিচালনা

  1. শিশু সুরক্ষা নিশ্চিতকরণ: রোগীর বয়স ১৮-এর কম হলে ছবি কোনো অবস্থাতেই ডিসপ্লে করা যাবে না।
  2. ৪টি যাচাই ধাপ: ১. হাসপাতালের কাগজ, ২. ডাক্তার প্রোটোকল, ৩. এনআইডি মিল, এবং ৪. ফিল্ড সাক্ষাৎ।
  3. কেস প্রকাশনা: ৪টি শর্ত পূরণ হলে তবেই "প্রকাশ করুন" (Publish) বাটন সক্রিয় হবে এবং প্রকাশের পর কেসটি ৩০ দিনের জন্য পাবলিক থাকবে।
  4. মেয়াদ বাড়ানো ("মেয়াদ বাড়াও"): নতুন চিকিৎসার অগ্রগতি লিখে সাবমিট করলে কেসের মেয়াদ আরও ৩০ দিন বৃদ্ধি পাবে।
৪

ক্যাশ ক্লিয়ারিং ও অপ্টিমাইজেশন

ওয়েবসাইটে কোনো ডাটা বা সেটিংস তাৎক্ষণিক আপডেট না হলে ব্রাউজার থেকে সরাসরি /clear-cache হিট করুন অথবা টার্মিনালে চালান: php artisan optimize:clear।

৩. জরুরি ট্রাবলশুটিং চিটশিট (Troubleshooting Cheat Sheet)

সমস্যা সম্ভাব্য কারণ সমাধানের কমান্ড
নতুন আপলোড করা ছবি দেখাচ্ছে না স্টোরেজ লিংক তৈরি নেই php artisan storage:link
পারমিশন বা রোলে অ্যাক্সেস সমস্যা পারমিশন ডাটা ক্যাশড হয়ে আছে php artisan permission:cache-reset
ক্রন জব বা মেয়াদ অটোমেটিক পরিবর্তন হচ্ছে না শিডিউলার সার্ভারে বন্ধ আছে php artisan schedule:run চালিয়ে টেস্ট করুন
সিএসএস বা টেলউইন্ড ডিজাইন ভেঙে গেছে Vite প্রোডাকশন বিল্ড মিসিং npm run build
সব ক্যাশ এক ক্লিকে মুছে ফেলতে কনফিগ/ভিউ/রুট ক্যাশ জ্যাম php artisan optimize:clear
