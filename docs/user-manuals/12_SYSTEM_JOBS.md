# ১২. সিস্টেমের স্বয়ংক্রিয় কাজ (Automated Jobs)

কেউ হাতে না চালালেও প্রতিদিন এই কাজগুলো নিজে থেকে চলে (সার্ভারে Laravel Scheduler সেট থাকলে — দেখুন [13_TECHNICAL_OPERATIONS.md](13_TECHNICAL_OPERATIONS.md))। এগুলোর তালিকা `routes/console.php`-এ কোডে লেখা আছে।

| সময় | কাজ | কী করে |
|---|---|---|
| রাত ০১:০০ | `ExpirePatientCases` | যে রোগীর কেসের মেয়াদ (৩০ দিন) পার হয়ে গেছে, তার status `expired` করে দেয় |
| রাত ০২:০০ | `sitemap:generate` | গুগল সার্চের জন্য sitemap.xml নতুন করে বানায় (সব প্রকাশিত ডাক্তার/হাসপাতাল/গাইড/কেস পাতা যোগ করে) |
| রাত ০৩:০০ | `RecalculateRatingSummaries` | যাচাইকৃত ডাক্তার-রেটিং দিয়ে প্রতিটা ডাক্তারের গড় স্কোর নতুন করে হিসাব করে (১০+ যাচাইকৃত রেটিং হলে প্রকাশযোগ্য করে) |
| সকাল ০৯:০০ | `NotifyCaseExpiring` | যেসব কেসের মেয়াদ ৫ দিনের মধ্যে শেষ হবে, সেগুলোর জন্য স্টাফকে অ্যাডমিন প্যানেলে নোটিফিকেশন পাঠায় |

## কোনটা কেন গুরুত্বপূর্ণ

- **`ExpirePatientCases`** না চললে মেয়াদ পার হওয়া কেস পাবলিক সাইটে "সক্রিয়" হয়ে থেকে যাবে — ভুল ধারণা তৈরি হবে যে সাহায্য এখনো দরকার।
- **`RecalculateRatingSummaries`** না চললে নতুন যাচাই হওয়া রেটিং কখনো ডাক্তারের প্রোফাইলে প্রতিফলিত হবে না, এমনকি ১০টা জমা হয়ে গেলেও প্রকাশ হবে না।
- **`sitemap:generate`** না চললে নতুন প্রকাশিত পাতা গুগলে দেরিতে ইনডেক্স হবে।

## এগুলো ম্যানুয়ালি চালাতে চাইলে (শুধু ডেভেলপার)

```bash
php artisan schedule:run   # যা যা সময় হয়ে গেছে সব একসাথে চালায়
php artisan queue:work     # জব প্রসেস করতে (Redis queue ব্যবহার হয়)
```
