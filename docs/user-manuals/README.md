# CancerCare Bangladesh (CCB) — ইউজার ম্যানুয়াল

এই ফোল্ডারটি পুরো CCB প্ল্যাটফর্মের ব্যবহারকারী নির্দেশিকা। প্রতিটি মডিউল কীভাবে কাজ করে, কনটেন্ট কোথা থেকে আসে, কে কী করবে, আর সিস্টেম নিজে থেকে কী করে — সবকিছু এখানে একটি নির্দিষ্ট কাঠামোয় লেখা আছে, যাতে সম্পূর্ণ নতুন কেউ পুরো সিস্টেমটা সহজে বুঝতে পারেন।

## এই ম্যানুয়াল কীভাবে পড়বেন

প্রথমবার পড়লে এই ক্রমে পড়ুন:

1. **[01_OVERVIEW.md](01_OVERVIEW.md)** — CCB আসলে কী, সিস্টেমের ৪টি অংশ (পাবলিক সাইট / অ্যাডমিন প্যানেল / ডাক্তার পোর্টাল / মাঠকর্মী পোর্টাল) কীভাবে একসাথে কাজ করে।
2. **[02_ROLES_AND_PERMISSIONS.md](02_ROLES_AND_PERMISSIONS.md)** — আপনি কোন ভূমিকায় আছেন (super_admin, verification_officer, doctor, রোগী...) এবং সেই ভূমিকায় ঠিক কী কী করতে পারবেন।
3. এরপর আপনার কাজের সাথে সংশ্লিষ্ট মডিউলের ফাইলটি পড়ুন (নিচের তালিকা দেখুন)।

এই ম্যানুয়ালটা প্রথম থেকে শেষ পর্যন্ত এক বসায় পড়ার জন্য নয় — প্রয়োজন অনুযায়ী নির্দিষ্ট মডিউলে যান।
